## Featured Project

### MuleSoft for Absolute Beginners

A structured, hands-on learning repository for Mule 4 and integration development.

The learning path covers:

- MuleSoft fundamentals, flows, connectors, and HTTP APIs.
- Guided API exercises, including CRUD, validation, external API calls, and a customer-integration capstone.
- Mule event model, routing, Scatter-Gather, and batch processing.
- Anypoint Platform and error-handling patterns.
- Salesforce Platform Events and event-driven integration.
- RAML 1.0 and APIkit implementation.
- DataWeave course with **24 worked examples** and **30 independent implementation problems**.
- Two API-led connectivity POCs: one using RAML/APIkit and another implemented without RAML, spanning System, Process, and Experience APIs.
