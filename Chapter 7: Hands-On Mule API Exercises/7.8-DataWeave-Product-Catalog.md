## Build the worked application

1. Create product-catalog-api with Listener path /catalog on port 8081.
2. Add Set Payload with the sample JSON array below, or use it as Transform Message preview input.
3. Add Transform Message and paste the DataWeave example.
4. Call GET http://localhost:8081/catalog and verify the product count and stock values.
5. Change prices and quantities, then add a product to observe the calculated output.

## Worked example

Use the relevant example below while building the tutorial application. Create global configurations through Studio and let Studio manage generated configuration IDs.

```text
Sample JSON:
[
  { "sku": "P-101", "name": "Pen", "price": 1.5, "quantity": 20 },
  { "sku": "P-102", "name": "Notebook", "price": 4, "quantity": 10 },
  { "sku": "P-103", "name": "Bag", "price": 25, "quantity": 2 }
]

DataWeave:
%dw 2.0
output application/json
var products = payload
---
{
  totalProducts: sizeOf(products),
  products: products map (product) -> {
    sku: product.sku,
    name: product.name,
    stockValue: product.price * product.quantity
  },
  totalStockValue: sum(products map ($.price * $.quantity))
}
```

## Troubleshooting checklist

- Confirm the Listener port is available and the app is running.
- Match the HTTP method and route exactly.
- For JSON requests, use Postman Body → raw → JSON.
- Query parameters are available under attributes.queryParams; URI template values are under attributes.uriParams.
- payload is the current message body, vars contains variables, and attributes describes the current message.
- HTTP Request replaces the current payload with its response unless you preserve the original data in a variable first.
