## Build the worked application

1. Create employee-directory-api with Listener path /employees/{employeeId}, port 8081.
2. Add Set Variable requestedEmployeeId with value #[attributes.uriParams.employeeId].
3. Add Transform Message using the example below.
4. Call GET http://localhost:8081/employees/1002?includeDepartment=true.
5. Try an unknown ID and includeDepartment=false.

## Worked example

Use the relevant example below while building the tutorial application. Create global configurations through Studio and let Studio manage generated configuration IDs.

```text
%dw 2.0
output application/json
var employees = [
  { id: "1001", name: "Asha", department: "Finance" },
  { id: "1002", name: "Rohan", department: "Engineering" },
  { id: "1003", name: "Meera", department: "Operations" }
]
var employee = employees filter ($.id == vars.requestedEmployeeId)
---
if (isEmpty(employee))
  { employeeId: vars.requestedEmployeeId, message: "Employee not found" }
else
  {
    employeeId: employee[0].id,
    name: employee[0].name,
    department: if ((attributes.queryParams.includeDepartment default "false") == "true") employee[0].department else null
  }
```

## Troubleshooting checklist

- Confirm the Listener port is available and the app is running.
- Match the HTTP method and route exactly.
- For JSON requests, use Postman Body → raw → JSON.
- Query parameters are available under attributes.queryParams; URI template values are under attributes.uriParams.
- payload is the current message body, vars contains variables, and attributes describes the current message.
- HTTP Request replaces the current payload with its response unless you preserve the original data in a variable first.
