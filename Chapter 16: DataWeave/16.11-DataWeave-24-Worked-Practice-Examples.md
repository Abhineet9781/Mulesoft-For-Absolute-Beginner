# 16.11 — 24 Worked DataWeave Practice Examples

Run each script with the stated input in Transform Message preview or the DataWeave Playground. The examples are deliberately small so that you can focus on one concept at a time. Output whitespace may differ, but output structure and values should match.

## Example 1 — Rename fields

Input: `{"id":7,"firstName":"Asha"}`

```dataweave
%dw 2.0
output application/json
---
{ customerId: payload.id, givenName: payload.firstName }
```

Output: `{"customerId":7,"givenName":"Asha"}`

## Example 2 — Concatenate a full name

Input: `{"first":"Asha","last":"Rao"}`

```dataweave
%dw 2.0
output application/json
---
{ fullName: trim(payload.first ++ " " ++ payload.last) }
```

## Example 3 — Default a missing value

Input: `{"name":"Ravi"}`

```dataweave
%dw 2.0
output application/json
---
{ name: payload.name, country: payload.country default "India" }
```

## Example 4 — Convert numeric strings

Input: `{"quantity":"4","price":"8.5"}`

```dataweave
%dw 2.0
output application/json
---
{ total: (payload.quantity as Number) * (payload.price as Number) }
```

## Example 5 — Filter active users

```dataweave
%dw 2.0
output application/json
---
(payload.users default []) filter ((u) -> u.active == true)
```

## Example 6 — Map product summaries

```dataweave
%dw 2.0
output application/json
---
(payload.products default []) map ((p) -> {
  sku: p.sku,
  label: p.name,
  price: p.price
})
```

## Example 7 — Add a line total

```dataweave
%dw 2.0
output application/json
---
(payload.lines default []) map ((l) -> {
  sku: l.sku,
  total: l.quantity * l.unitPrice
})
```

## Example 8 — Calculate a grand total

```dataweave
%dw 2.0
output application/json
---
sum((payload.lines default []) map ((l) -> l.quantity * l.unitPrice))
```

## Example 9 — Number each row

```dataweave
%dw 2.0
output application/json
---
(payload.items default []) map ((item, index) -> {rowNumber: index + 1, item: item})
```

## Example 10 — Sort by price

```dataweave

(payload.products default []) orderBy ((p) -> p.price)
```

## Example 11 — Keep one record per ID

```dataweave

(payload.customers default []) distinctBy ((c) -> c.id)
```

## Example 12 — Group orders by status

```dataweave
%dw 2.0
output application/json
---
(payload.orders default []) groupBy ((o) -> o.status default "UNKNOWN")
```

## Example 13 — Build a summary

```dataweave
%dw 2.0
output application/json
var orders = payload.orders default []
---
{
  count: sizeOf(orders),
  total: sum(orders map ((o) -> o.total default 0)),
  average: if (isEmpty(orders)) 0 else sum(orders map ((o) -> o.total default 0)) / sizeOf(orders)
}
```

## Example 14 — Flatten order lines

```dataweave
%dw 2.0
output application/json
---
(payload.orders default []) flatMap ((o) ->
  (o.lines default []) map ((l) -> {orderId: o.id, sku: l.sku, quantity: l.quantity})
)
```

## Example 15 — Convert object entries to an array

Input: `{"metrics":{"cpu":0.4,"memory":0.7}}`

```dataweave
%dw 2.0
output application/json
---
pluck(payload.metrics, (value, key) -> {name: key, value: value})
```

## Example 16 — Transform object values

```dataweave
%dw 2.0
output application/json
---
(payload.settings default {}) mapObject ((value, key) -> {(key): upper((value as String))})
```

This assumes every setting value is string-coercible.

## Example 17 — Conditional discount

```dataweave
%dw 2.0
output application/json
var total = payload.total as Number
---
{ total: total, discount: if (total >= 500) total * 0.1 else 0 }
```

## Example 18 — Pattern-match status

```dataweave
%dw 2.0
output application/json
---
{
  message: (payload.status default "UNKNOWN") match {
    case "NEW" -> "Received"
    case "PAID" -> "Payment accepted"
    case "SHIPPED" -> "Dispatched"
    else -> "Check status"
  }
}
```

## Example 19 — Normalize email

```dataweave
%dw 2.0
output application/json
---
{ email: lower(trim(payload.email default "")) }
```

## Example 20 — Parse and reformat a date

```dataweave
%dw 2.0
output application/json
var d = payload.date as Date {format: "dd/MM/yyyy"}

{ date: d as String {format: "yyyy-MM-dd"} }
```

## Example 21 — Convert an object to CSV rows

```dataweave
%dw 2.0
output application/csv header=true
---
(payload.people default []) map ((p) -> {
  id: p.id,
  name: p.name,
  active: p.active

```

## Example 22 — Create an optional field

```dataweave
%dw 2.0
output application/json
var phone = payload.phone default null
---
{ id: payload.id } ++ (if (phone == null or phone == "") {} else {phone: phone})
```

## Example 23 — Use a lookup object

Input includes `vars.productNames` in a Mule flow.

```dataweave
%dw 2.0
output application/json
---
(payload.lines default []) map ((l) -> {
  sku: l.sku,
  name: (vars.productNames default {})[l.sku] default "Unknown product",
  quantity: l.quantity
})
```

## Example 24 — Row-level validation report

```dataweave
%dw 2.0
output application/json
---
(payload.records default []) map ((r, i) -> {
  row: i + 1,
  id: r.id default null,
  valid: r.id != null and r.amount != null and (r.amount as Number) >= 0,
  errors: []
    ++ (if (r.id == null) ["Missing id"] else [])
    ++ (if (r.amount == null) ["Missing amount"] else [])
})
```

This example assumes that non-null amounts are valid numeric values; malformed numeric strings need a separate safe validation/error strategy.

## Practice protocol

For each example:
1. Reproduce it without copying.
2. Write a new input containing an empty array.
3. Remove one optional field.
4. Try a null value.
5. Explain the output type and why the chosen function fits.
6. Add one automated test.

These examples are starting patterns, not universal production policies. Confirm null behavior, coercion, date formats, and function signatures in your target runtime.
