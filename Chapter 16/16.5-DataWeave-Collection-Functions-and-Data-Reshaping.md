# 16.5 — Collection Functions and Data Reshaping

This is a core intermediate topic. Choose a function based on the shape you want, not simply because you remember its name.

## 1. Essential collection functions

| Function | Typical purpose | Result |
|---|---|---|
| `map` | Transform each array item | Array |
| `filter` | Keep matching array items | Array |
| `flatMap` | Map, then flatten one level | Array |
| `flatten` | Flatten nested arrays one level | Array |
| `reduce` | Accumulate items into one value | Accumulator's type |
| `groupBy` | Group by a key/function | Object of groups |
| `orderBy` | Sort by a key/function | Array |
| `distinctBy` | Keep distinct values by key | Array |
| `pluck` | Turn object key/value pairs into array entries | Array |
| `mapObject` | Transform each object key/value pair | Object |
| `filterObject` | Keep matching object entries | Object |
| `sizeOf` / `isEmpty` | Inspect collection size/emptiness | Number / Boolean |
| `sum`, `min`, `max` | Aggregate numeric values | Number/value |

Check the function reference for overloads and supported input types.

## 2. map vs mapObject

`map` is for array elements. `mapObject` is for object entries.

```dataweave
%dw 2.0
output application/json
---
{
  names: (payload.users default []) map ((u) -> u.name),
  normalizedSettings: (payload.settings default {}) mapObject ((value, key) -> {
    (lower(key)): value
  })
}
```

## 3. filter and filterObject

```dataweave
%dw 2.0
output application/json
---
{
  expensive: (payload.products default []) filter ((p) -> p.price >= 100),
  enabledSettings: (payload.settings default {}) filterObject ((value, key) -> value == true)
}
```

## 4. flatMap and flatten

Use `flatMap` when one source record produces zero or more output records. Use `flatten` when the data is already nested into arrays and only one level should be removed.

```dataweave
%dw 2.0
output application/json
---
(payload.departments default [])
  flatMap ((d) -> (d.employees default []) map ((e) -> {
    department: d.name,
    employee: e.name
  }))
```

## 5. reduce

`reduce` carries an accumulator through the array. It is useful for custom aggregates and reshaping that standard functions cannot express simply.

```dataweave
%dw 2.0
output application/json
---
(payload.lines default []) reduce ((line, total = 0) ->
  total + ((line.quantity default 0) * (line.price default 0))
)
```

For empty arrays, decide explicitly what result should be returned; test empty inputs for the reducer form you use.

## 6. groupBy

```dataweave
%dw 2.0
output application/json
---
(payload.orders default []) groupBy ((order) -> order.status default "UNKNOWN")
```

This produces an object whose keys represent statuses and whose values are arrays of matching orders. Grouping changes the output shape; downstream consumers may need an array rather than a grouped object.

## 7. orderBy and distinctBy

```dataweave
%dw 2.0
output application/json
---
{
  byPrice: (payload.products default []) orderBy ((p) -> p.price),
  uniqueCustomers: (payload.customers default []) distinctBy ((c) -> c.customerId)
}
```

Do not assume the first duplicate is the most recent or authoritative unless the input order and rule guarantee that. Deduplication policy is a business decision.

## 8. pluck

`pluck` iterates over object entries and emits an array. This is useful when the object keys themselves carry meaning.

```dataweave
%dw 2.0
output application/json
---
pluck(payload.metrics, (value, key) -> {
  metric: key,
  value: value
})
```

## 9. Aggregation example — order totals by status

```dataweave
%dw 2.0
output application/json
var orders = payload.orders default []
---
{
  orderCount: sizeOf(orders),
  totalValue: sum(orders map ((o) -> o.total default 0)),
  byStatus: orders groupBy ((o) -> o.status default "UNKNOWN")
}
```

## Practice examples

### Example 9 — Top-level distinct categories

```dataweave
%dw 2.0
output application/json
---
distinctBy((payload.products default []) map ((p) -> p.category))
```

### Example 10 — Summary per customer

```dataweave
%dw 2.0
output application/json
---
(payload.orders default []) groupBy ((o) -> o.customerId)
  mapObject ((orders, customerId) -> {
    (customerId): {
      orderCount: sizeOf(orders),
      total: sum(orders map ((o) -> o.total default 0))
    }
  })
```

## Debugging strategy

For each collection function, write down:
1. Input type.
2. Lambda parameter type.
3. Result type.
4. Behavior for empty input.
5. Behavior for null/missing input.
6. Whether order is meaningful or preserved.
