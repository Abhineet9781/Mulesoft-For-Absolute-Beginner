# 16.7 — Object Transformations, Flattening, and Dynamic Keys

## 1. Rename and restructure fields

```dataweave
%dw 2.0
output application/json
---
{
  customerId: payload.customer.id,
  fullName: trim((payload.customer.firstName default "") ++ " " ++ (payload.customer.lastName default "")),
  contact: {
    email: payload.customer.email default null,
    phone: payload.customer.phone default null
  }
}
```

Explicit construction is often clearer and safer than copying every input property into the output.

## 2. Merge objects

Object concatenation with `++` is useful for composing a common base with optional fields. Be cautious with duplicate keys and precedence; test which value wins in the exact expression you write.

```dataweave
%dw 2.0
output application/json
var base = { source: "crm", active: true }
var enriched = { customerId: payload.id, active: payload.active default true }
---
base ++ enriched
```

Prefer avoiding duplicate keys if possible; when overriding is intentional, make the order obvious.

## 3. Conditional fields

```dataweave
%dw 2.0
output application/json
var phone = payload.phone default null
---
{
  id: payload.id,
  name: payload.name
  ++ (if (phone != null and phone != "") { phone: phone } else {})
}
```

This pattern omits phone when it is not supplied. Compare with explicitly emitting `phone: null`; the choice must match the downstream contract.

## 4. Flatten nested data

Suppose each order contains lines and each line has SKU and quantity. Use `flatMap` to produce one row per line:

```dataweave
%dw 2.0
output application/json
---
(payload.orders default [])
  flatMap ((order) ->
    (order.lines default []) map ((line) -> {
      orderId: order.id,
      sku: line.sku,
      quantity: line.quantity,
      lineTotal: line.quantity * line.unitPrice
    })
  )
```

This is a common export/reporting transformation. Include parent identifiers so flattening does not lose relationships.

## 5. Pivot-like object from an array

```dataweave
%dw 2.0
output application/json
---
(payload.inventory default []) reduce ((item, acc = {}) ->
  acc ++ { (item.sku): item.available }
)
```

This creates a SKU-to-available-quantity object. Duplicate SKUs overwrite according to object merge behavior, so validate uniqueness or define the aggregation rule explicitly.

## 6. Object to array and array to object

Use `pluck` to convert object entries to an array; use `groupBy` or `reduce` when an array needs to be keyed. Keying is only safe when the key is unique or collisions have a defined policy.

## 7. XML and namespaces

XML is hierarchical and can include repeated elements, attributes, and namespaces. In DataWeave, namespace declarations and XML selectors are required when namespaced elements are present. Do not assume XML is identical to JSON: XML attributes and repeated elements may serialize differently.

Conceptual example:
```dataweave
%dw 2.0
output application/json
ns ord http://example.com/order
---
{
  orderId: payload.ord#Order.@id,
  lines: payload.ord#Order.ord#Line map ((line) -> {
    sku: line.@sku,
    quantity: line.Quantity
  })
}
```

Treat the namespace URI as part of the XML contract; replace the example URI with the actual one.

## 8. CSV output

For CSV, the output is usually an array of row objects with consistent columns. Configure the CSV writer's separator, header, quoting, and line-ending behavior when needed. Nested objects and arrays generally need to be flattened or serialized deliberately before CSV output.

```dataweave
%dw 2.0
output application/csv header=true
---
(payload.orders default []) map ((o) -> {
  orderId: o.id,
  customerId: o.customerId,
  total: o.total
})
```

## Practice examples

### Example 13 — Flatten orders to line records

```dataweave
%dw 2.0
output application/json
---
(payload.orders default []) flatMap ((o) ->
  (o.lines default []) map ((l) -> {orderId: o.id, sku: l.sku})
)
```

### Example 14 — Convert metrics object into records

```dataweave
%dw 2.0
output application/json
---
pluck(payload.metrics default {}, (value, key) -> {name: key, value: value})
```
