# Chapter 16 — DataWeave: Beginner to Intermediate

DataWeave is MuleSoft's expression and transformation language. This chapter is a structured, implementation-oriented course aimed at **intermediate proficiency**: reading and writing transformations, reasoning about types and nulls, reshaping nested data, composing functions, handling real integration payloads, and testing transformations.

> **Version note:** Examples use DataWeave 2.x syntax for Mule 4. Confirm runtime-specific module functions against the documentation for the Mule runtime you use. DataWeave is not JavaScript: syntax that looks similar can behave differently.

## Learning outcomes

By the end, you should be able to:
- Explain the DataWeave execution model, MIME types, headers, directives, and expressions.
- Use variables, functions, lambdas, scopes, types, coercion, selectors, and pattern matching.
- Transform JSON, XML, CSV, and Java-like objects into a target structure.
- Confidently use `map`, `mapObject`, `filter`, `filterObject`, `reduce`, `groupBy`, `orderBy`, `distinctBy`, `pluck`, `flatten`, and related functions.
- Work with missing fields, null values, defaults, dates, strings, numbers, and errors.
- Split transformations into reusable modules and test them in Studio/MUnit.
- Diagnose common bugs and avoid fragile, expensive transformations.

## How to practice effectively

For every example, first predict the output without running the code. Then run it in the Transform Message preview or DataWeave Playground, compare the result, and explain *why* it is correct. Change the input shape, omit a field, introduce null, and test an empty array. A transformation is not robust until edge cases are considered.

## Prerequisites

Know basic JSON, arrays, objects, HTTP APIs, and the Mule event payload. Chapter 6 introduces Transform Message; Chapter 7 contains small integration applications. Revisit those as needed.
