# Chapter 4 — Setup and Installation

## 4.1 Anypoint Studio Installation

**Anypoint Studio** is MuleSoft's desktop IDE for creating, running, and debugging Mule applications.

### Before you install

- Check the current operating-system and hardware requirements in the [official Anypoint Studio documentation](https://docs.mulesoft.com/studio/to-download-and-install-studio).
- Download Studio only from MuleSoft's official documentation/download links.
- Choose a Studio version compatible with the Mule runtime and Java version required by your project. The latest Studio release may have different requirements from older tutorials.

### Install on Windows

1. Open the [official Anypoint Studio installation guide](https://docs.mulesoft.com/studio/to-download-and-install-studio-wx).
2. Download the Windows package linked from the guide.
3. Extract the downloaded archive to the location specified by the guide—MuleSoft recommends extracting it under `C:\` so the application is in `C:\AnypointStudio\`.
4. Open the extracted folder and launch `AnypointStudio.exe`.
5. If Windows Firewall asks about the embedded Java/OpenJDK process, allow it only if the download came from the official MuleSoft source and your organization permits it.
6. Choose a workspace folder when prompted. A workspace is where Studio stores your projects and related settings.

### Install on macOS or Linux

1. Open the [official Anypoint Studio installation guide](https://docs.mulesoft.com/studio/to-download-and-install-studio).
2. Select the instructions for your operating system and download the supported package.
3. Follow the platform-specific extraction or installation steps in the guide.
4. Launch Anypoint Studio and choose a workspace folder.

### Verify the installation

When Studio opens successfully:

- Confirm that the workbench/editor is visible.
- Create or import a Mule project using the options available in your Studio version.
- Check the project’s configured Mule runtime and Java compatibility before running it.

> **Tip:** Installation screens can change between versions. Use the official guide for your operating system rather than following screenshots for an older release.
