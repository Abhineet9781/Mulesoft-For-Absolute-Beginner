# Chapter 4 — Setup and Installation

## 4.2 Postman Installation

**Postman** is an API client used to send requests and inspect responses. It is useful for testing an API before connecting to it from a Mule application.

### Install Postman Desktop

1. Open the [official Postman download page](https://www.postman.com/downloads/).
2. Select the download for your operating system: Windows, macOS, or Linux.
3. Run the downloaded installer or follow the platform-specific installation instructions.
4. Open Postman. Sign in or create an account if prompted; account requirements can vary by feature.
5. Create a new HTTP request so you are ready to test an API.

For detailed operating-system instructions and requirements, see the [official Postman installation guide](https://learning.postman.com/docs/getting-started/installation/install-app).

### Quick installation check

1. Open Postman and create a new request.
2. Set the method to **GET**.
3. Enter this public test endpoint:

   `https://postman-echo.com/get`

4. Click **Send**.
5. A successful test should return an HTTP success response (normally **200 OK**) with request information in the response body.

This checks that Postman can send a basic request and display its response; it does not test your own API.

### Desktop app or web app?

Postman also offers a [web app](https://go.postman.co/). Some features require the desktop app; if using the web app to send requests to local or private services, follow Postman's guidance for the Desktop Agent.

> **Safety tip:** Do not put passwords, API keys, or other secrets directly into shared requests or public collections.
